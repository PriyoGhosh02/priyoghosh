# 📖 About

This portfolio represents my professional work as a Full Stack Web Developer. It highlights my technical skills, featured projects, work experience, education, certifications, and contact information in a clean, modern, and responsive interface.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/PriyoGhosh02/priyoghosh.git
```

Move into the project

```bash
cd priyoghosh
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production

```bash
npm run preview
```
